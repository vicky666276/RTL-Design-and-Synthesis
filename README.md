# RTL Design and Synthesis using SKY130 Standard Cell Libraries

## Overview

This repository documents the complete hands-on workflow performed during the **RTL Design and Synthesis Workshop** using **Verilog HDL**, **Yosys**, **GTKWave**, and **SKY130 standard cell libraries**.  

The workshop focused on understanding the complete RTL-to-Gate-Level design flow including:
- RTL coding using Verilog HDL
- Simulation and verification
- Waveform analysis
- Logic synthesis
- Technology mapping
- Gate-level schematic generation

The experiments and lab sessions were performed in a Linux-based virtual environment using Oracle VirtualBox and Ubuntu/Xubuntu.

---

# Workshop Objectives

The primary objectives of this workshop were:

- Understand the fundamentals of RTL design
- Learn Verilog HDL coding techniques
- Perform simulation using Icarus Verilog
- Analyze waveforms using GTKWave
- Understand synthesis flow using Yosys
- Explore SKY130 standard cell libraries
- Learn technology mapping concepts
- Understand gate-level implementation of RTL designs
- Study optimization techniques in synthesis
- Explore Gate-Level Simulation (GLS)
