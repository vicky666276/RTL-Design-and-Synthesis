## 📌 Overview

This repository contains the hands-on work completed during the **RTL Design and Synthesis Workshop using SKY130 Standard Cell Libraries**.

The workshop focused on understanding the complete RTL Design Flow using open-source EDA tools, beginning from Verilog RTL coding to synthesis and gate-level implementation.

The practical sessions covered:
- RTL Design using Verilog HDL
- Simulation using Icarus Verilog
- Waveform Analysis using GTKWave
- RTL Synthesis using Yosys
- Technology Mapping using SKY130 Standard Cell Libraries
- Gate-Level Netlist and Schematic Generation
- RTL Optimization Techniques

## 📖 About SKY130

SKY130 is an open-source Process Design Kit (PDK) that provides standard cell libraries and technology data required for ASIC design using open-source EDA tools.

The SKY130 library enables practical RTL-to-GDSII implementation flow and technology mapping for digital VLSI design.
